# Credit risk spectral model

Master's thesis project: credit risk assessment and early default
prediction using Chebyshev, Legendre, Walsh and Haar features.

## Data
Download "Default of Credit Card Clients" from the UCI Machine Learning
Repository and place the file in the data/ folder.

## Setup
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
